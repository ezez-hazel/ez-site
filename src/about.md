# 关于本站

最开始只是为了做直播推送注册的域名，后来想着域名都有了干脆直接做个网站。说是这么说但完全不知道摇做什么，目前计划的定位是做个工具站，再加一点简单资讯。不做时效性较强的资讯~~因为站长是个懒狗~~。

本站使用的媒体（包括图片、音频、视频等）

## 关于友链

本站欢迎各位绿冻同担交换友链，相关内容可以通过GitHub Issues提交。

### 友链和外链的区别

本站会随缘收集一些小满相关的网站，这些单方面收集的网站就是外链。如果其中某个网站的所有人交换了友链，那么这个网站就会被移动到友链中。
